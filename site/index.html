Music production has a gatekeeper: the interface. Setloom removes it.

The piano roll, the plug-in maze, the mixing-desk vocabulary: decades of craft stacked between you and the idea already playing in your head. The only skill Setloom asks for is the one you already have: hearing a track and knowing whether it moves you.

You direct. The agent produces.

One division of labor runs Setloom: the human owns the taste, the agent owns the production, and the harness owns technical hygiene only. Nothing is final until you say so.

Youthe listener and creative director

You give direction in plain language: the bass is too busy before the break; make the arp darker. You judge the result and decide whether it is accepted or needs revision.

The agentthe producer

It brings taste and makes purposeful, distinctive musical choices within your brief. It composes, edits, renders, inspects, and improves weak material before delivery. Rejected work gets a concrete revision; metrics never override your verdict.

The harnessthe studio

A small, unopinionated toolkit that scaffolds tracks, renders, inspects audio, and keeps the work reproducible. It owns technical hygiene only. It composes nothing.

Audition, react, revise.

Every pass is short. The agent prepares and plays the audio the way you prefer; you listen and type. The listening gate is no-click.

A small toolkit, run from the keyboard.

Command-line tools and opt-in diagnostics. The toolkit never composes the music; each track's own source does that.

setloom new
Scaffold a track: spec, runnable assembler, and listening-notes template from one command.
assemble.py
Each track's editable code assembles the music. Every render is reproducible from source.
setloom play
Audition a render the way you prefer. Nothing autoplays without your say.
setloom inspect
Waveform, spectrum, spectrogram, stereo field, and A/B comparisons from the command line.
setloom transcribe
Recover note candidates from reference audio with a native MLX Basic Pitch engine on Apple Silicon.
setloom anatomize
Dissect a reference by layers to study how it is put together.
setloom.midi, setloom.audio, setloom.conductor
MIDI, DSP hygiene, and music-theory primitives that each track's code builds on.
SuperCollider, Logic Pro, Ableton Live
Local production surfaces the agent can drive when a track calls for them, with editable source and recorded settings.

Quick start: one command scaffolds a track.

Setloom runs through a single repo-local uv environment. Everything generated is file-based and reproducible; audio and model weights stay out of Git.

Read the full quick start on GitHub

Terminal 
# scaffold a track; assemble.py starts as a skeleton the agent fills in
$ uv run setloom new T06 --title midnight-signal --bpm 124 --key "F# minor"
$ uv run --no-sync python music/tracks/T06/assemble.py

# audition and inspect the render
$ uv run setloom play local/candidates/T06/seed-0/demo.wav
$ uv run setloom inspect local/candidates/T06/seed-0/demo.wav --view all

# study a reference: recover its notes, then read its anatomy
$ uv run --group transcription setloom transcribe reference.wav --out tmp/notes.mid
$ uv run setloom anatomize local/corpus/audio --layers

Not a one-click generator. Composition is not solved.

What works today is the loop: an agent that turns feedback into concrete source changes quickly, researches when it helps, renders and inspects reproducibly, and keeps the workspace clean enough that the next pass continues without forensics. The leverage is disciplined iteration, not automation that replaces judgment. Setloom is honest about where that frontier sits.

Questions, answered plainly.

What is Setloom?
Setloom is an open-source, keyboard-first harness for producing club tracks and DJ sets with an AI agent. You give direction in plain language and judge the result by ear; the agent composes, edits, renders, inspects, and revises each track's editable source. It is made by App Automaton and licensed AGPL-3.0.
Is Setloom a one-click music generator?
No. Composition is not solved, and Setloom does not pretend otherwise. What works today is a disciplined loop: an agent that turns your listening notes into concrete source changes, renders and inspects reproducibly, and keeps the workspace clean enough that the next pass continues without forensics.
Do I need a DAW, Ableton Live, or Logic Pro?
No. You never operate a DAW or a plug-in. Each track is editable source that the agent assembles and renders. SuperCollider, Logic Pro, and Ableton Live can serve as local production surfaces when a track calls for them, driven by the agent rather than by you.
What does the agent do, and what do I do?
You are the listener and creative director: you say what is wrong and whether the result is accepted. The agent is the producer: it makes the musical choices within your brief, writes the track's code, renders an audition, and revises rejected work. The harness is the studio: it scaffolds, renders, inspects, and keeps everything reproducible, and it composes nothing.
What does Setloom run on?
Python 3 through one repo-local uv environment. Audio-to-MIDI transcription uses a native MLX Basic Pitch engine on Apple Silicon Macs; the rest of the toolkit is command-line Python. Model weights, audio, and proprietary samples stay out of Git.
Who owns the music Setloom produces?
You do, subject to the third-party samples, models, and inputs you bring. The code is AGPL-3.0-only and the documentation is CC BY-SA 4.0.
