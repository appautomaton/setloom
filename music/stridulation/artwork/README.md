# Artwork source

The cover was generated with the built-in image tool. The second prompt added
(Setloom Mix), preserving STRIDULATION, APP AUTOMATON and the existing artwork.
Both exact prompts are included here; no raster image is stored in this folder.

The retained generated image and its provenance are in
local/releases/stridulation/artwork in the Setloom workspace. Supply that PNG with
rebuild.py --cover to embed it in the M4A. Audio generation does not require it.
Regenerating from the prompt can create a new interpretation, not identical pixels.
