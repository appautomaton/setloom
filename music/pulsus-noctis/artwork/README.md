# Pulsus Noctis cover

`cover.webp` retains the approved complete cover at its original dimensions,
using high-quality lossy WebP with an embedded color profile. `prompt.txt` is
the generation prompt. Image and lettering were generated together.

`prepare_package.py --audio FILE --out-dir DIRECTORY` reads this cover and
copies the WebP alongside an explicitly selected WAV without image conversion. It does not upload or
process the audio. Use an empty directory under project `tmp/`.
