# Ableton Production

Start from the intended musical effect and the current performance, arrangement,
patches, and listening feedback. Use [Workflow](../../../docs/workflow.md) for
working stages, acceptance, and continuity.

Choose each part's role, rhythm, articulation, and sound from the brief. Preserve
useful musical identity while composing the changes between sections. Genre
labels and previous-track choices are not a prescribed musical recipe. For a
reference-based instrument change, use
[instrument reinterpretation](../../../docs/reconstruction.md#instrument-reinterpretation).

When working in Live, inspect the actual tracks, clips, devices, and available
instruments. Use `$ableton-mcp` for current tool schemas and backend limits. If a
needed control is unavailable, inspect other authorized methods before handing
studio operations back to the user.

Read only the relevant detail:

- [Expressive arrangement](../setloom-expressive-arrangement/SKILL.md): develop a
  lead melody into complementary electronic layers, motion and space.
- `references/workflows.md`: arrangement, performance, mix, and export decisions.
- `references/core-concepts.md`: Live object identity, timing and control units.
- `references/source-grounding.md`: integration provenance; not current capabilities.
